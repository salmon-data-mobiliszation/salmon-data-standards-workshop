This lesson helps participants create and review Salmon Data Packages from data they already have. By the end, participants can turn reviewed package metadata into a validated EML 2.2 file and prepare a guarded upload to an EML-aware catalog such as KNB. It starts with package structure and context, then adds links to shared definitions where they matter most.

The coded walkthrough is R-first. Python companion blocks follow the core creation and review steps, and spreadsheet participants work with the same standard package files. The final EML and KNB/DataONE publication workflow taught here runs in the R `metasalmon` package against the current SDP specification.
