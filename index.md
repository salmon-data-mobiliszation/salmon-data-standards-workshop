This lesson helps participants create and review Salmon Data Packages from data they already have. The common pathway is FAIR publication: preserve context, link selected meanings to shared definitions, export validated EML 2.2, and prepare a guarded upload to an EML-aware catalog such as KNB. Learners can go further by proposing missing shared terms or by planning how an organizational vocabulary or ontology will be governed and mapped to the Salmon Domain Ontology as a shared interoperability layer.

Code-driven activities include matching R and Python lanes, and spreadsheet-specific subsections work with the same standard package files without requiring code. The R `metasalmon` and Python `metasalmonpy` implementations are maintained at behavioral parity while retaining idiomatic syntax for each language.
